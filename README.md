# 算法设计与分析 — 第4章 迭代算法

> 武汉科技大学 · 算法设计与分析课程课件 · Slidev 制作

## 内容

本课件涵盖第4章「基本的算法策略」中的迭代算法部分：

- **4.1.1 递推法** — 兔子繁殖（Fibonacci）、最大公约数（欧几里得算法）
- **4.1.2 倒推法** — 猴子吃桃、杨辉三角、穿越沙漠问题
- **4.1.3 迭代法解方程** — 方程组迭代、牛顿迭代法、二分法求根

## 使用

```bash
# 安装依赖
npm install

# 启动开发服务器
npx slidev slides.md --port 3160

# 导出 PDF
npx slidev export slides.md

# 导出 PPTX
npx slidev export slides.md --format pptx
```

浏览器打开 http://localhost:3160 即可查看，按空格键或点击翻页。
